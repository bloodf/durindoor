Choose a deployment for your host. Each guide covers prerequisites, persistent storage, startup, verification, and recovery. Before allowing remote access, set private secrets, require inference API keys, and configure TLS.

After the app responds locally, use the reverse-proxy guide to verify forwarding headers, streaming, and dashboard assets.
