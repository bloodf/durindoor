---
title: DurinDoor documentation
description: One gateway in front of every AI provider, with an OpenAI-compatible API.
---

DurinDoor is a self-hosted AI gateway. You add provider credentials once in the dashboard, then point tools at `http://localhost:20128/v1` instead of wiring each app to a different vendor. Credentials stay on your machine. DurinDoor translates OpenAI-shaped requests for Claude, Gemini, Kiro, Cursor, Ollama, Vertex, and other upstream formats. Per request, the dashboard shows the provider, the model, tokens, cost estimates, latency, and fallback outcome.

Start here if you want a first request through the gateway. Operators running DurinDoor on a team server use the deployment and operations pages. The contributing section is for people changing the codebase or the provider registry. DurinDoor is a fork of 9router. Existing installs keep their data, keys, and headers.

`npm install -g durindoor`, then `durindoor`. Open http://localhost:20128/dashboard, sign in, add a provider connection, and create an API key. Send the request to http://localhost:20128/v1. Getting started covers that path. The cards name the other sections.
