Use Claude Code's Anthropic transport to send requests through DurinDoor. You need a running gateway, a DurinDoor key, a chat-capable connection or combo, and the `claude` CLI.

```bash
npm install -g @anthropic-ai/claude-code
claude --version
```

## Apply from the dashboard

1. Open **CLI Tools → Claude Code**.
2. Choose the gateway endpoint, key, and model values for Opus, Sonnet, Fable, and Haiku.
3. Select a context-window preset or leave **Default**.
4. Click **Apply** and start a new Claude Code process.

Apply updates `~/.claude/settings.json` on the DurinDoor host. It merges environment values and marks onboarding complete. If the tool runs elsewhere, configure its file manually.

Apply preserves an existing `ANTHROPIC_AUTH_TOKEN`. To replace a stale or upstream token, edit the file yourself or reset the card before applying the new key. Reset removes the endpoint, auth token, Opus/Sonnet/Haiku defaults, timeout, and context override. It leaves other settings, including the Fable default, in place.

For Claude model defaults, omit a leading `cc/`. Apply removes that prefix because Claude Code can copy the value into its subagent schema. For a combo, use the exact saved combo name.

## Configure manually

Merge the following into `~/.claude/settings.json`. Replace the token and model values with ones available on your instance.

```json
{
  "hasCompletedOnboarding": true,
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128/v1",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_DURINDOOR_API_KEY",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-5",
    "ANTHROPIC_DEFAULT_FABLE_MODEL": "claude-fable-5-1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5-20251001"
  }
}
```

Or set the endpoint and key in the shell before starting the process:

```bash
export ANTHROPIC_BASE_URL="http://localhost:20128/v1"
export ANTHROPIC_AUTH_TOKEN="YOUR_DURINDOOR_API_KEY"
claude --model sonnet "Reply with one short sentence."
```

The shell command assumes the Sonnet default is already configured. Model availability depends on your connected account. DurinDoor adapts model-picker IDs, including supported `[1m]` suffixes, back to gateway model IDs. An advertised context window does not guarantee every combo member supports that window.

## Choose optional compatibility settings

**Filter naming** answers Claude Code topic-naming requests locally. It does not change ordinary chat responses.

**Classifier** is off by default. The compatibility modes can synthesize an allow response for Claude Code's internal auto-permission classifier. **Auto** detects classifier requests and answers them locally. **Always** applies broader fallback and response handling to Claude-format traffic. These settings can change auto-approval behavior; use a signed-in operator session to change them.

Leave the context preset at **Default** to use the model's limit. The 200K and 1M presets store 198000 and 998000 respectively. Choosing a larger preset does not expand the upstream model's limit.

## Verify and troubleshoot

Send the short prompt above and confirm the request on **Usage**. For an independent Anthropic request, follow [First request](../getting-started/first-request.mdx).

If curl works but Claude Code fails, restart Claude Code and check its settings file and shell environment for a stale token. A 400 involving a subagent model can mean a `cc/` prefix remains in `ANTHROPIC_DEFAULT_*_MODEL`. If auto mode blocks every action, inspect the classifier response and compatibility setting rather than changing the provider credential.
