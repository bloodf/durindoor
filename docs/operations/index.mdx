Operate an installed gateway with the procedures below. Verify inference after each restart or upgrade; health checks confirm only the HTTP listener.

Before a restore or database switch, identify the active engine, preserve its data and encryption keys, and stop traffic during the maintenance window. Use [Deployment](../deployment/index.mdx) for the first install.
