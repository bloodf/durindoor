
Atlas Cloud is available as an API-key provider with OpenAI-compatible chat and model discovery.

SubQ is available as an API-key provider for the System One endpoint.

ParalonCloud uses the connection’s API key for chat, embeddings, and authenticated model discovery. Use `paraloncloud/<model>` or `paralon/<model>`; the bundled catalog remains available. See the [Inference API documentation](https://paraloncloud.com/docs/inference-api) for streaming, usage, and current model availability.

Parallel provides web search and Markdown extraction with an API key; search supports mode and domain filters.

NaN.Builders supports chat, embeddings, transcription, speech, images, image edits and reranking; quota usage is shown per model when available.
