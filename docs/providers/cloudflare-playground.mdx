Cloudflare Playground is an anonymous, text-only provider. It requires no API key or cookie. The gateway connects to the playground's `cf_agent` chat protocol through a browser context because its WebSocket upgrade expects a browser TLS fingerprint. Cloudflare documents its Agents chat framework, but does not publish a public API contract for this Playground protocol.

## Setup

No credentials are needed. Select a listed model and send text messages. The current upstream model catalog may change. The pinned executor does not support image, audio, video, document, or file inputs; tool calls are emulated. Cloudflare controls anonymous rate limits; rate-limit frames are returned as quota errors.

Sources: [Cloudflare Agents chat docs](https://developers.cloudflare.com/agents/agent-class/communication-channels/chat/chat-agents/), [Cloudflare AI Playground](https://playground.ai.cloudflare.com/).
