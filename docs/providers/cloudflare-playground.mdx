title: Cloudflare AI Playground
description: Use the anonymous, text-only Cloudflare AI Playground models without a key or cookie.
---

Cloudflare Playground is an anonymous, text-only provider. It requires no API key or cookie. The pinned OmniRoute executor connects to the playground's `cf_agent` chat protocol through a browser context because its WebSocket upgrade expects a browser TLS fingerprint. Cloudflare documents its Agents chat framework, but does not publish a public API contract for this Playground protocol.

## Setup

No credentials are needed. Select a listed model and send text messages. The current upstream model catalog may change. The pinned executor does not support image, audio, video, document, or file inputs; tool calls are emulated. Cloudflare controls anonymous rate limits; rate-limit frames are returned as quota errors.
