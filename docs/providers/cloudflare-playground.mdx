Cloudflare Playground is an anonymous, text-only provider. It requires no API key or cookie. The gateway connects to the playground's `cf_agent` chat protocol through a browser context because its WebSocket upgrade expects a browser TLS fingerprint. Cloudflare documents its Agents chat framework, but does not publish a public API contract for this Playground protocol.

## Setup

No credentials are needed. Select a listed model and send text messages. The current upstream model catalog may change. The pinned executor does not support image, audio, video, document, or file inputs; tool calls are emulated. Cloudflare controls anonymous rate limits; rate-limit frames are returned as quota errors.

## Tool calling

The playground has no native function calling, so the gateway emulates it: your tool definitions go into the prompt, and the model's text reply is read back as tool calls. Reliability depends on the model.

- A call is returned only when it names a declared tool and its arguments pass the checks DurinDoor applies to the tool's schema: types, enums, required keys, closed objects and array items. Other JSON Schema keywords are not checked.
- A reply with an invalid, cut-off or partly invalid call is returned as ordinary text and none of its calls run. The gateway does not ask the model again.
- With tools declared, a streamed answer arrives after the model finishes, not token by token. A reply that ends before completion is reported as HTTP 502.

The playground accepts at most 10 user messages of 6000 characters each, and tool results count as user messages. In requests that carry tools or tool history, the gateway truncates oversized messages and compacts older turns into one summary message, so long agent sessions lose detail from earlier turns. The tool list also uses some of those 10 messages. A very large toolset that does not fit in eight of them is cut off, and the tools left out are not described to the model. The playground ignores `system` messages.

The tool contract has at most eight chunks. Tools beyond that limit are omitted, and the gateway logs the number omitted.
