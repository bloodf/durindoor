title: g4f Groq
description: Availability of the g4f Groq endpoint and the current integration status.
---

The configured route lists `g4f-groq` at `https://g4f.space/api/groq/v1`. The g4f public API documentation identifies `https://g4f.space/api/groq` as its Groq provider. A single unauthenticated request to the pinned model-list endpoint `https://g4f.space/api/groq/v1/models` returned HTTP 404 on 2026-11-21 (Cloudflare address `172.67.169.115`). DurinDoor does not currently implement this route. This is endpoint evidence at the recorded time, not a claim that the entire g4f service is unavailable.

Sources: [g4f API endpoints](https://g4f.dev/docs/ready_to_use.html).
