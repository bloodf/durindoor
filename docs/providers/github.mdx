---
title: GitHub Copilot
description: Sign in to GitHub Copilot with a device code.
---

GitHub Copilot (`github`, alias `gh`) uses GitHub's device-code sign-in.

1. Open **Dashboard → Providers**, choose **GitHub Copilot** and start device
   sign-in. The terminal CLI offers the same flow.
2. Open the GitHub device page, enter the code, and approve it with the account
   that holds the Copilot subscription.

A cancelled, expired or denied code saves nothing; start a new sign-in.

Public GitHub, [GitHub Enterprise Copilot](./ghe-copilot.mdx) and
[Microsoft 365 Copilot Web](./copilot-m365-web.mdx) are separate identities.
Credentials from one cannot be used for another.
