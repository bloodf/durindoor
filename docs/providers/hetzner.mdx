---
title: Hetzner Inference
description: Connect to the experimental Hetzner Inference API.
---


Hetzner Inference is an experimental OpenAI-compatible service. Add a Hetzner Inference API token in the provider dashboard, then refresh the connection's model list. Hetzner's authenticated model endpoint is the authoritative list and can change during the experiment; model IDs can contain slashes. Address a model as `hetzner/<model-id>`, preserving the full ID returned by Hetzner.

The gateway uses bearer authentication and the chat completions endpoint. Availability and rate limits are subject to the [Hetzner Inference contract](https://docs.hetzner.com/general/company-and-policy/experiments/inference/).
