# MaxAI

MaxAI is a browser-backed web app, not a public API-key service. DurinDoor follows OmniRoute's pinned MaxAI executor: `POST https://api.maxai.me/gpt/cwc/chat`, a browser-minted Bearer access token and a request signature bound to the matching device and user identifiers. The access token expires and must be renewed through a browser session; the refresh endpoint is browser/TLS gated.

## Setup and session capture

Sign in at [MaxAI](https://www.maxai.co/app/) in a browser. Import the MaxAI session from the extension, or paste a Cookie header / cURL command / HAR from the signed-in app. Keep `access_token`, `device_id`, and `user_id` from the same browser session together; the token and identifiers are connection-specific. The signer also needs current client signing constants. Reconnect through a browser session when the access token expires or MaxAI rotates its public web client.

The staged provider includes a capture profile for `www.maxai.co` and `api.maxai.me`. Do not paste a token from another account into the captured session. All catalog models are account and plan dependent; the included model list is the OmniRoute release/v3.8.55 catalog snapshot and can become stale. MaxAI controls access, pricing, rate limits, and service availability.

## Limits

MaxAI's web endpoint is not a stable public API contract. Tool calling, vision, reasoning, and usage reporting can differ by model; usage is not currently reported by the web stream. The web session can expire, requests can be blocked by browser/TLS checks, and server-side validation cannot refresh a session.
