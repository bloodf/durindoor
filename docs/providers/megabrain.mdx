---
title: MegaBrain Gateway
description: Connect to MegaBrain Gateway with an API key.
---


Create an API key in MegaBrain and add a MegaBrain API-key connection. Sync models and select a returned ID, for example `mb/openai/gpt-6.1-sol`. The `mb/` prefix selects the provider; the vendor-qualified ID is forwarded unchanged.

The [documented gateway](https://getmegabrain.com/docs) supports model discovery and OpenAI-compatible Chat Completions, including streaming. Requests are subject to MegaBrain account and balance requirements. OAuth and anonymous access are not configured by this integration.
