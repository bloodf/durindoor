---
title: PromptQL (experimental)
description: Use your own signed-in PromptQL playground session and enrich-token JWT, with its limits and errors.
---

PromptQL is an unofficial, experimental integration for a user's own signed-in playground session. It calls the playground GraphQL operations with the project-scoped `enrich-token` JWT and project ID. This is reverse-engineered web application behavior and is not a documented third-party API. Use it only while it works with your account; PromptQL can change the web app, auth flow, model catalog, or limits without notice.

## Setup

Sign in at [prompt.ql.app](https://prompt.ql.app) and import the playground cookies with **Import cookies** or the cookie capture extension. The first chat exchanges the session for a playground enrich-token and uses the project ID from the connection, session, or token claims. DurinDoor saves the token and resolved project on that connection after a successful turn and uses the imported session to refresh the token near expiry.

Cookie exchange depends on the experimental playground endpoint returning a chat-capable token. If exchange fails, re-import the session. You can also supply the playground `enrich-token` JWT and project ID as `token` and `projectId` in the connection's provider-specific data. Obtain the JWT from the Authorization header of a playground GraphQL request to `data.prompt.ql.app`. A DDN project token is for project credits. Keep session cookies and JWTs out of logs, issues, and test fixtures.

## Models, limits, and errors

Model discovery reads the signed-in project's `FetchLlmConfigs` GraphQL catalog. The registry model list is an offline fallback; the connection lists live models when its provider-specific data carries a manually supplied JWT. Chat starts a roomless PromptQL thread, sends the latest user message, and polls thread events until it can return an OpenAI-compatible completion or stream. Follow-up requests may pass `promptql_thread_id` or `X-PromptQL-Thread-Id` to continue a thread.

Usage and billing follow the PromptQL account/project. DurinDoor maps expired/unauthorized sessions to 401 and quota/rate limiting to 429. This web session flow has not been independently verified as a supported vendor API contract; model availability, billing, refresh behavior, and limits may vary. No separate usage endpoint is exposed; the **Usage** card shows only what DurinDoor recorded for the connection.
