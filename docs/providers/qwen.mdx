---
title: Qwen Code
description: Sign in to Qwen Code with a device code and keep it separate from Qwen Cloud API keys.
---

Qwen Code (`qwen`, alias `qw`) uses a device-code OAuth sign-in.

1. Open **Dashboard → Providers**, choose **Qwen Code** and start sign-in.
   Choose the connection's proxy first; the connection keeps using it.
2. Open the verification URL shown in the dashboard and enter the code.
3. Keep the dashboard open until the connection appears.

The terminal CLI offers the same device sign-in.

Qwen Cloud API keys (`qwen-cloud`) are a separate provider with their own
regions. Do not import them into Qwen Code.

A cancelled or expired code saves nothing; start a new sign-in. A finished
sign-in cannot be completed a second time.
