---
title: "SYNTX API availability"
description: Current verification status for the SYNTX API endpoint.
---

SYNTX uses `https://api.syntx.ai/api/v1` for chat.

A single unauthenticated GET to the pinned documented chat route, `https://api.syntx.ai/api/v1/chat/completions`, returned HTTP 404 on 2026-11-21. The available public SYNTX help pages describe in-app chatbot usage and request limits, not a third-party API credential or a supported external API endpoint. The public developer documentation host did not return a readable document during this check. No provider was implemented because the pinned API route returned 404 and a working, documented vendor API could not be established.

Sources: [SYNTX public help](https://docs.syntx.ai/en/%F0%9F%92%A1-Text/%F0%9F%92%A1-Text).
