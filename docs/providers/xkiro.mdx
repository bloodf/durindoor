---
title: X-Kiro
description: Connect an X-Kiro API key and select models.
---


Add an **X-Kiro** API-key connection in Providers, then sync its model list. Select a model using the full vendor-prefixed ID, for example `xkiro/openai/gpt-5.6-sol`. X-Kiro is separate from Kiro OAuth and Amazon Q. The catalog can change and account access depends on X-Kiro; check its [model catalog](https://xkiro.com/models) and [API documentation](https://docs.xkiro.com/). Connection testing uses the authenticated usage endpoint. Live account-backed verification has not been performed.
