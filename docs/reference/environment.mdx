title: Environment variables
description: Operator variables from .env.example and every process.env read in src, open-sse, custom-server.js, and cli.
---

Copy the starter file `.env.example` into `.env` before a production boot. Fill every placeholder. Blank strings are deleted at process start, so Docker `-e FOO=` is the same as leaving `FOO` unset.

<Callout type="warn">
`JWT_SECRET` is required on a fresh data dir. DurinDoor does not mint `DATA_DIR/jwt-secret`. An existing file from an older install is reused with a warning. Generate a value with `openssl rand -hex 32`.
</Callout>

Tables list the code default when the variable is unset, what it does, and the primary read site. `.env.example` may ship a different starter value (Firecrawl timeout is 30000 there; the code default is 15000).

## Production secrets

| Variable | Default | Purpose | Read in |
| --- | --- | --- | --- |
| `JWT_SECRET` | none | Signs dashboard session tokens. Env wins. Legacy `DATA_DIR/jwt-secret` is accepted with a warning. Missing both throws. | `src/lib/auth/dashboardSession.js` |
| `INITIAL_PASSWORD` | `123456` | Dashboard password when none is stored. Remote login with the built-in default is refused. | `src/lib/auth/dashboardSession.js` |
| `API_KEY_SECRET` | minted at `DATA_DIR/api-key-secret` when `DATA_DIR` is set | Secret that signs API key checksums. Set it when minted keys must survive recreate. | `src/shared/utils/apiKey.js` |
| `MACHINE_ID_SALT` | `endpoint-proxy-salt` | Salt for the machine id embedded in generated API keys. | `src/shared/utils/machineId.js` |
| `AUTH_COOKIE_SECURE` | `false` | `true` forces secure dashboard cookies. Otherwise https on `BASE_URL` / `NEXT_PUBLIC_BASE_URL` or the request URL decides. | `src/lib/auth/dashboardSession.js` |

Native default `DATA_DIR` remains `~/.9router` on macOS/Linux and `%APPDATA%\9router` on Windows.

## Outbound proxy

Dashboard proxy settings write `NINE_ROUTER_PROXY_MANAGED` plus the matching URL and no-proxy vars. Process-level `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY` (and lowercase twins) are also read. Loopback targets (`localhost`, `*.localhost`, `0.0.0.0`, `127.0.0.0/8`, `::`, `::1`, and IPv4-mapped loopback) never use an outbound proxy.
