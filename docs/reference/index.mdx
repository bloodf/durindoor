Look up a `/v1` route, an environment variable, a CLI flag, a plugin manifest field, or a model context window. These pages follow the current source. They are not a getting-started path.

The API page lists every `route.js` under `src/app/api/v1`. Clients still call `/v1/...`. Next rewrites that prefix onto `/api/v1`. Management REST under `/api/*` is a separate page. The other cards cover environment, the `durindoor` launcher, the plugin manifest, model limits, and the 9router cutover.
