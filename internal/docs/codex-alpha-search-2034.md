# Codex Alpha Search (#2034)

The first-party wire contract is pinned to [OpenAI Codex f29d55ff, endpoint/search.rs](https://github.com/openai/codex/blob/f29d55ff0697a88226e8a9811b3c007e5f719cba/codex-rs/codex-api/src/endpoint/search.rs) and [search.rs](https://github.com/openai/codex/blob/f29d55ff0697a88226e8a9811b3c007e5f719cba/codex-rs/codex-api/src/search.rs). The endpoint test serializes a SearchRequest and expects JSON SearchResponse; commands and results can be absent. It is distinct from DurinDoor's generic search API.

[CLIProxyAPI 6faa8d20, internal/api/server_routes.go](https://github.com/router-for-me/CLIProxyAPI/blob/6faa8d20b2673404cff70a2f2d9537ae0d0e684d/internal/api/server_routes.go) maps both paths to one handler, selects Codex credentials and uses the fixed ChatGPT OAuth URL. It strips prompt cache fields, and supports additional API-key destinations outside this unit's scope. DurinDoor uses its own key policy, account selection, proxy resolution, bounded transport and quota lifecycle; it does not copy caller identity headers or forward upstream error bodies.

[OmniRoute 632d84f5, alpha/search/route.ts](https://github.com/cheaper-inference/OmniRoute/blob/632d84f569f72893ed148e5b19dd05e2fff1a52a/src/app/api/v1/alpha/search/route.ts) adapts query operations to generic search providers and explicitly rejects several commands; it is not OAuth passthrough. [EasyCLIProxyAPI e4223d5e, core-version.txt](https://github.com/router-for-me/EasyCLIProxyAPI/blob/e4223d5eefa22a3301ca7e2a28d05897432b07f9/core-version.txt) identifies its bundled core as 8.0.63; its [core update script](https://github.com/router-for-me/EasyCLIProxyAPI/blob/e4223d5eefa22a3301ca7e2a28d05897432b07f9/scripts/update-bundled-core.mjs) manages that separate core. Its [issue #646](https://github.com/router-for-me/EasyCLIProxyAPI/issues/646) describes delegation and requests fallback to a different Codex model for non-Codex routes. This implementation requires the requested route to resolve to Codex and does not substitute a model or account outside existing selection policy.

No live upstream request was made. OAuth authentication does not guarantee Alpha Search entitlement; 401/403 responses are returned as sanitized failures and no attestation or authorization bypass is attempted.
