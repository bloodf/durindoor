# Devin CLI sign-in and ACP parity (#2034)

Compared pinned snapshots, not live accounts:

- [CLIProxyAPI `6faa8d20`, `sdk/auth/devin.go`](https://github.com/router-for-me/CLIProxyAPI/blob/6faa8d20b2673404cff70a2f2d9537ae0d0e684d/sdk/auth/devin.go) implements its own Devin OAuth sign-in; [service registration](https://github.com/router-for-me/CLIProxyAPI/blob/6faa8d20b2673404cff70a2f2d9537ae0d0e684d/sdk/cliproxy/service_executors.go) selects its [Devin executor](https://github.com/router-for-me/CLIProxyAPI/blob/6faa8d20b2673404cff70a2f2d9537ae0d0e684d/internal/runtime/executor/devin_executor.go). This is a separate contract, not evidence that DurinDoor's local ACP adapter should use those credentials or HTTP transport.
- [EasyCLIProxyAPI `e4223d5e`, `src/pages/EasyModePage.tsx`](https://github.com/router-for-me/EasyCLIProxyAPI/blob/e4223d5eefa22a3301ca7e2a28d05897432b07f9/src/pages/EasyModePage.tsx) offers Devin OAuth; [management callbacks](https://github.com/router-for-me/EasyCLIProxyAPI/blob/e4223d5eefa22a3301ca7e2a28d05897432b07f9/src-tauri/src/management_api.rs) delegate to its separately versioned core. Its UI does not define the ACP request contract.
- [OmniRoute `fbd33966`, `open-sse/executors/devin-cli.ts`](https://github.com/cheaper-inference/OmniRoute/blob/fbd339668384803bc3a9d42370fc413a55e013d5/open-sse/executors/devin-cli.ts) runs a summarizer subprocess, supplies the connection token through `WINDSURF_API_KEY`, sends `mcpServers: []` and `prompt`, and accepts nested `agent_message_chunk` text. DurinDoor ports these request and response fields while retaining its import-token flow in `src/lib/oauth/providers.js`.

The offline regression uses fake tokens and mocked subprocesses with outbound fetch closed. It checks two concurrent connections and sessions. It does not verify a real CLI version, login, installed CLI credential fallback, model availability, cancellation, tool use, or live provider behavior. Hosted Devin and the agentic provider are separate and unchanged. The adapter remains text-only and estimates token usage.

Each summarizer subprocess has its own incremental UTF-8 decoder. The executor decodes stdout before splitting on newlines, so a multibyte character can span reads without corrupting an ACP JSONL record. The offline regression interleaves partial reads from two children, checks nested text blocks, and verifies the final SSE frames and stdin closure.

The adapter retains the legacy initialization payload (`protocolVersion: "0.3"`, `clientInfo`, and `capabilities`) also used by the pinned OmniRoute executor above. The ACP Registry's November 19, 2026 probe records a successful version 1 handshake for Devin CLI `3000.14.30821`. The probe source sends an integer `protocolVersion` with `clientCapabilities`, and the Devin registry entry launches plain `devin acp`. That result establishes support for the registry invocation. Negotiation for `devin acp --agent-type summarizer` with imported credentials remains unverified, so this change preserves the existing payload.
