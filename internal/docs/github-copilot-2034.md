Enterprise has separate host normalization and exchange in `open-sse/config/gheCopilot.js` and `open-sse/services/gheCopilotAuth.js`. These boundaries were not changed.

A non-JSON device poll response formerly consumed the body twice and threw before returning an error. The single-read parsing fix follows OmniRoute `src/lib/oauth/providers/github.ts`. The mock tests exercise device approval, pending/denied polls, credential separation, malformed polling responses, and the refresh threshold. Existing catalog and Responses streaming tests exercise additional mock behavior. These tests do not establish live entitlements, current server acceptance, every streaming event, Enterprise end-to-end behavior, or complete parity with upstream.

Existing Messages and Responses stream translation remains in use. No runtime behavior changed in this comparison.
