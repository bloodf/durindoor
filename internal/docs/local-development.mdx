Pin Node.js `20.20.2` and npm `10.8.2`. You also need Git, and a browser if you are changing the dashboard.

## Install

```bash
nvm use
npm ci --no-audit --no-fund
cd tests && npm ci --no-audit --no-fund
```

## Isolate development data

<Callout type="warn">
Default `DATA_DIR` is `~/.9router`. Point `HOME` and `DATA_DIR` at disposable directories before any command that can start the app or inspect storage.
</Callout>

Do not point development commands at an operator database.

```bash
export HOME="$PWD/.dev-home"
export DATA_DIR="$PWD/.data-dev"
mkdir -p "$HOME" "$DATA_DIR"
```

Those directories hold credentials and databases. Keep them untracked. Delete them only after you confirm they are disposable. Default storage without `DATA_DIR` is `~/.9router`.

## Run the app

```bash
npm run dev
```

`npm run dev` is `node scripts/next-owner-server.cjs --dev --port 20127`. The wrapper binds `127.0.0.1` unless `HOSTNAME` is set. Open `http://localhost:20127/dashboard`.

Production from source:

```bash
npm run build
npm start
```

`npm start` runs `.next/standalone/custom-server.js` on port `20128` unless `PORT` is set. CLI starts also use `20128`.

## Lint and anti-slop

```bash
npm run lint
```

That command is `eslint src && npm run lint:anti-slop`. `lint:anti-slop` rebuilds the plugin and runs oxlint:

```bash
node scripts/build-anti-slop-plugin.mjs && node scripts/check-anti-slop.mjs
```

Husky `pre-commit` runs lint-staged, then `npm run lint:anti-slop`. lint-staged runs eslint with `--max-warnings=0` on staged `src/**/*.{js,jsx,mjs}`. Either step failing blocks the commit.

The plugin is vendored at `tools/oxlint/anti-slop/`. It is not an npm package. oxlint loads `tools/oxlint/anti-slop/index.bundle.js`. After you edit the TypeScript sources, rebuild with `node scripts/build-anti-slop-plugin.mjs` (the first command inside `lint:anti-slop`).

The gate is zero diagnostics. `scripts/check-anti-slop.mjs` reprints oxlint output and exits 1. Do not baseline. `.oxlintrc.json` sets every generic anti-slop rule to `"error"`. Effect rules stay off. Ignore patterns cover editor dirs, `.omc/`, `tools/oxlint/anti-slop/**`, `node_modules`, `.next`, coverage, and test files (`tests/**`, `**/*.{test,spec}.*`). Production sources including `src/`, `open-sse/`, `cli/`, and `scripts/` must stay clean.

`typeof` is banned (`anti-slop/no-runtime-typeof`). Use `src/shared/utils/typeChecks.js` or `typeChecks.cjs`: `isString`, `isNumber`, `isBoolean`, `isFunction`, `isObject`, `isUndefined`, `isSymbol`, `isBigInt`, `isBrowser`, `runtimeTypeName`. Those helpers match ECMAScript `typeof` tags without using `typeof`.

Do not put `shape` in identifier names (`anti-slop/no-shape-in-symbol-names`). Use domain words (`layout`, `payload`, `form`). For PropTypes, call `PropTypes["shape"](...)`.

Refresh notes and the vendored SHA live in [tools/oxlint/anti-slop/VENDOR.md](https://github.com/bloodf/durindoor/blob/main/tools/oxlint/anti-slop/VENDOR.md). Current SHA: `6d538555cb151d4121ed51a27db81890eacf8ae9`.

## Storybook

```bash
npm run storybook
```

That is `storybook dev -p 6006`. Open `http://localhost:6006`. Tokens and primitives live under `src/shared/ui/`. `npm run storybook:build` writes `storybook-static/`. Coverage against that build is `npm run check:storybook-coverage`.

The source catalog in `tests/e2e/storybook-surfaces.json` separates proposed classification and parent-story ownership from independent source approval and runtime acceptance. Refresh hashes from the actual accepted source, archive superseded approval scope, and leave changed contracts pending review. Historical census counts and absent planning paths are not current inventory limits or recreated snapshots. Source-only approval never certifies the full browser matrix.

Read-only native endpoint fields must be asserted through their named textbox's live value, `readOnly`, visibility, focus, and applicable selection behavior. Text content, placeholders, attributes, and descriptive manifest control metadata do not enforce native values. Programmatic `select()` does not certify trusted keyboard selection or clipboard delivery; verify those separately on the frozen real surface, including font loading and narrow-width wrapping.

For MCP server presets, assert the named URL textbox's live value through the real CSF play; use the retained **Server preset** label for visible-text expectations, not the URL value. Preserve rejected proposal dispositions verbatim as revision-bound history, even when they were wrong; record later source and ownership corrections separately at the actual revision rather than rewriting the historical record.

Keep completed MCP creation separate from retained form coverage. The submitted creation story saves through the real modal, leaves a rendered instance row, and asserts that the dialog has unmounted; its final result belongs to the page, instances panel, and created row. A separate unsubmitted Custom scene keeps the actual production modal and private form/guidance children open, scopes its heading and controls to that dialog, asserts live editable draft values and an enabled Save action, and verifies no created row exists. Use real retained labels/guidance as text evidence, never native draft values or the page's “New instance” opener. Preserve submission, persistence, keyboard and full-process accessibility obligations alongside retained-modal coverage.

MCP instances and keys each have their own retained error story: the actual respective production wrapper and shared error view stay mounted with heading, body/help text, and an enabled retry action. Separate reset stories assert the initial production error, activate retry, then assert `Reset requested` and absence of the production heading and retry action after the harness conditionally unmounts the error. Neither retained wrapper scene aliases the other. Console interception matches only the complete exact two-argument fixture call, forwards every other argument list unchanged, and restores the spy on disposal; the intercepted call is not a captured browser-console event. Preserve initial/error/retry/reset process evidence, fixture reset, renderer-owned asynchronous unmount, cleanup error rejection, and native A/B/A isolation obligations.

Apply the same retained-versus-transition boundary to Combos errors. The retained scene keeps the actual production title/help, enabled retry action, and dashboard link mounted. Separate retry/load-failure stories assert removal of those elements and end in harness recovery text, not a restored production page. Match only the complete exact two-argument fixture diagnostic, forward every unexpected argument unchanged, and restore interception; the intercepted call is not a runtime console event. A cancelled create-form story likewise proves an initial-edit-cancel-unmount process, while existing spacing/error/save scenes supply retained form coverage. Do not substitute an opener, parent heading, or broad closed-final waiver for private widget content or full-process evidence.

## Playwright

`npm run test:ui` is `playwright test --config playwright.config.mjs`. A real run needs `DURIN_QA_HARD_DIR` set to an absolute path under `qa/runs`. The config throws if that variable is missing or points outside `qa/runs`.

The intended runner is `tests/e2e/compose.yml`, which starts `tests/e2e/qa-child-entry.mjs`. That entry refuses to run unless `DURIN_QA_HARDENED=1`. Specs live in `tests/e2e`. Default workers: 1. Projects cover chromium, firefox, and webkit, each in dark and light, desktop and mobile.

Storybook stories:

```bash
npm run test:storybook
```

That sets `DURINDOOR_QA_MODE=storybook` and runs `tests/e2e/storybook.spec.js`.

The runner measures effective targets after intersecting viewport and internal clipping, uses the visible center for real hits, and requires focus and a 44px effective target. Closed disclosure descendants are not painted targets, but the actionable summary remains audited. Only a genuine modal, open popover, or fullscreen top-layer boundary stops ancestor clipping; a dialog role alone does not.

Chart-axis incomplete qualification is narrowly associated with actual source/story families and requires live opaque foreground/surface tokens, qualified low-alpha gradients, conservative composited contrast, and text/stroke separation. Masks, extra linked SVG text runs, unresolved geometry or paint, and unsupported non-scaling strokes cannot be assumed harmless. Standards/enhanced violations and all other incompletes remain failures; historical screenshots or diagnostics are not current qualification or manual accessibility approval.

After independent source review and explicit bookkeeping approval, freeze one tracked-only candidate for the same actual canary/sample selections and every current built story across all twelve browser/theme/viewport projects. Preserve Next.js document, theme, locale/direction, fonts, owned-client scope, native keyboard, full-process A/AA/AAA and independent manual evidence requirements. Neither source hashes, a build, nor isolated native diagnostics close runtime acceptance.

## Debugging

Use test data before turning these on:

```bash
LOG_LEVEL=DEBUG
ENABLE_REQUEST_LOGS=true
VALIDATE_OUTBOUND=false
CURSOR_STREAM_DEBUG=1
CURSOR_PROTOBUF_DEBUG=1
DEBUG_MITM=1
```

`LOG_LEVEL` defaults to `INFO`. `ENABLE_REQUEST_LOGS` is on only when the value is the string `true`; request-log bodies are stored as `{ redacted: true, present, type, bytes }`, not payload text. `VALIDATE_OUTBOUND` is on unless the value is `false`. Cursor stream and protobuf logs print when those variables equal `"1"`. MITM debug logs print when `DEBUG_MITM` is set.

Keep diagnostics opt-in. Disable them after diagnosis.
