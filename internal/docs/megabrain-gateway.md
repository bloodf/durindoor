# MegaBrain Gateway source notes

The pinned OmniRoute `open-sse/config/providers/registry/megabrain/index.ts` at `4624250231f49ed118fb4522a9d735e4894322c6` identifies the provider and `mb` alias, but uses an older OpenRouter-shaped endpoint and device OAuth. The current first-party [documentation](https://getmegabrain.com/docs) and [OpenAI guide](https://getmegabrain.com/openai-api) document bearer keys, Chat Completions, streaming and model discovery at `https://getmegabrain.com/api/gateway/v1`. This integration uses that public contract; the older OAuth contract remains unverified. No live account or provider call was used to validate it. Catalog contents and availability can change.

The first-party pages also advertise a keyless free model (`mb-auto/free`) and the API key page at `https://getmegabrain.com/keys`. Neither is configured here: the registry entry is an API-key connection only, so no anonymous or free-tier path is assumed. Model IDs keep their publisher prefix (`openai/gpt-6.1-sol`), and the `mb/` prefix is the client-facing provider prefix. The upstream catalog is read live through `GET https://getmegabrain.com/api/gateway/v1/models`, so the seeded model list is empty and discovery fills it.
