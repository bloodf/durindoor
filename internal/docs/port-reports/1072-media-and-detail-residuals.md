- [#5548](https://github.com/decolua/9router/pull/5548), head `03753fde62338efacf83deb9c8ecd18f651a110a` — **Existing endpoint; no direct port.** `src/sse/handlers/imageEdit.js` already routes `/v1/images/edits`, enforces client key and resolved model policy, scopes credential selection by key, and records edit usage. `open-sse/handlers/imageEditCore.js` forwards native FormData for multipart providers and supports the fork's JSON provider path. `tests/unit/image-generation.test.js` covers native FormData and edit accounting. Upstream instead normalizes uploads into generation JSON, rejects masks, and accepts multipart `image[]`; local multipart requires `image` and forwards masks. These contracts are not identical; do not replace the existing handler or claim all upstream validation and input forms are present.
- [#5547](https://github.com/decolua/9router/pull/5547), head `540ba56b6f3b9ab88b04b70424859ed1a0ca3ec7` — **Applicable, deferred; incomplete fork-wide adaptation.** The media page uses the shared `ConnectionsCard` and its global `isActive` toggle; credential selection has no `disabledKinds` filter. Upstream introduces per-kind selection but does not include this fork's separate image-edit handler, which uses quota preflight and key-scoped connections. A complete port must include edit and every affected dispatch and fallback path, preserve API-key relation restrictions and global disable semantics, and test save-to-dispatch, quota preflight, and unrelated chat routing. The source also leaves music, image-to-text, and systemone on the global switch. No partial feature is claimed here.
- [#5424](https://github.com/decolua/9router/pull/5424), head `370f5fb40bdb7f66e5b86c96d6e9d0d9578418aa` — **Inapplicable to current detail UI.** Upstream fixes direct React rendering of structured response content and separates thinking text. The fork's `src/app/api/usage/request-details/route.js` replaces all four payloads with redacted metadata, including for legacy rows; `RequestDetailsTab.js` shows that metadata and renders the already-redacted detail with a JSON tree. `tests/unit/request-details-metadata-ui.test.js` protects the absence of raw payload display and copy. Introducing upstream's raw response formatter would not supply readable content under this contract; exposing it would change the privacy and history behavior. No dashboard source or inventory was changed.

The existing endpoint and UI evidence establishes the local contracts, not equivalence to every upstream feature. No provider calls were made.
