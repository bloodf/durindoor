To select a workspace through the OAuth API, POST to `/api/oauth/codex/authorize` with `meta.allowed_workspace_id` set to its account ID. Complete the returned flow as usual; exchange-time metadata cannot change the selection. A returned ID token must identify that workspace. Refresh responses may omit an ID token, but any returned ID token must identify the same workspace. Selected flows require an authorization code rather than a pasted access token.

Compared with 9router master at `5ae63d22847e07042e235b40e1d926b65e509013`; master does not yet include the selected-workspace OAuth parameter. OmniRoute `release/v3.8.55` resolved to `5ffa68e835442a12ed1204a2eebf4076c298aecb`.
