## Ported

The [model format list](../../../open-sse/config/providerModels.js) includes Responses for catalog and synced model IDs. Chat and Messages clients that send typed server tools stay on their native transport ([chatCore](../../../open-sse/handlers/chatCore.js)).

Test: [port-5844-kimi-platform-responses.test.js](../../../tests/unit/port-5844-kimi-platform-responses.test.js).
