## Gemini prices: ported in this change

- [pricing.js](../../../open-sse/providers/pricing.js): `gemini-3.8-flash*` corrected to $0.75 / $3.75 / $0.075 cached; `gemini-3.6-flash*`, `gemini-embedding-2` and `gemini-embedding-2-preview` added.
- `gemma-4-31b-it` is $0 under `PROVIDER_PRICING.gemini`, not in the provider-agnostic table as upstream has it. The source is the Gemini API page, so a global row would also zero the cost, and bypass spend budgets, for other hosts of that id.
- `gemini-4-*` already carried $2 / $10 / $0.10 cached before this change.
- Rates are the upstream author's reading of Google's page on 2026-11-24; the live page was not re-read here. Scheduled changes: `gemini-4-*` doubles on 2026-12-01, Flash 3.6/3.8 on 2027-01-01.
- Test: [port-9router-5846-gemini-prices.test.js](../../../tests/unit/port-9router-5846-gemini-prices.test.js). Old 3.8 Flash expectations were updated in two existing tests because upstream changed the rate.

## Per-model price override: already present

User rates resolve ahead of built-in rates in [pricingRepo.js](../../../src/lib/db/repos/pricingRepo.js) (`resolvePricingForModel`) and are edited from the [pricing settings page](../../../src/app/dashboard/settings/pricing/page.js). Upstream's per-row price chip and price card are a different UI for the same override and were not copied.

## Per-key spend limit: already present

Daily, weekly and monthly USD budgets per key are defined in [apiKeyPolicy.js](../../../src/lib/db/helpers/apiKeyPolicy.js) and return 429 from [apiKeyLimits.js](../../../src/lib/apiKeyLimits.js). DurinDoor uses local calendar windows; upstream uses UTC. Upstream also disables its limit for keys that can reach unpriced models. That rule belongs to its own key-access feature and was not ported.
