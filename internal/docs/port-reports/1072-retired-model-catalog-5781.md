# 1072: retired public model catalog

Reviewed 2026-11-20 against https://github.com/decolua/9router/pull/5781, open and unmerged at head `3b3f36b3c91a6989ea68f2f4bb70257b574b6966`; local base `0a95887394726b8fbabb3eafddf4fd45d5b9ee28`. This is a partial port of static direct-provider catalog removals, not a migration of user data.

## Primary evidence and disposition

[Anthropic's model deprecations](https://platform.claude.com/docs/en/about-claude/model-deprecations) records `claude-3-5-sonnet-20241022` retired 2025-10-28 (notice 2025-08-13), and `claude-sonnet-4-20250514` and `claude-opus-4-20250514` retired 2026-06-15 (notice 2026-04-14). They were already absent from the local direct Anthropic registry but remained the CLI's only direct Anthropic choices; replace those CLI entries with the two upstream replacements already in the local registry. Keep the existing registry order, current aliases and broader model inventory.

[OpenAI's deprecation history](https://developers.openai.com/api/docs/deprecations) records `o1-mini` shutdown 2025-10-27 (notice 2025-04-28); `dall-e-2` and `dall-e-3` shutdown 2026-05-12 (notice 2025-11-14); and `gpt-4-turbo`, `gpt-4.1-nano`, `o3-mini`, `o4-mini` and `gpt-image-1` shutdown 2026-10-23 (notice 2026-04-22). The same notice explicitly covers the locally listed snapshots `gpt-4-turbo-2024-04-09`, `gpt-4.1-nano-2025-04-14`, `o3-mini-2025-01-31` and `o4-mini-2025-04-16`; remove these direct static rows too. `o1-mini`, `dall-e-2` and `dall-e-3` were already absent from the local direct OpenAI registry; remove `o1-mini` and `gpt-4-turbo` from the CLI. Other independently documented shutdowns are outside this source's scope.

The local OpenAI registry already has the three upstream GPT 5.6 choices and the 2.5 image choices; preserve its order and separately supported entries. Upstream's `gpt-image-2.6-sunburst` addition and default promotions are outside this static-removal port. The CLI retains its existing other choices. The local catalog includes further models and route metadata absent from the upstream diff, including Responses-format routing; don't replace the whole list.

Anthropic notes partner-operated platforms have their own schedules. In particular, local `kilocode`, `avalai`, `inner-ai`, `aimlapi` and OpenRouter entries are distinct routes; OpenRouter still lists `openai/gpt-image-1` and `openai/dall-e-3`. No global ID filter is justified. Compatible provider public IDs can be derived from custom inventory and saved aliases in `src/app/api/v1/models/buildModelsList.js`; static removal does not delete those sticky entries. Custom models and aliases persist in `src/lib/db/repos/aliasRepo.js`, and saved combo members are read independently in `open-sse/services/compact.js`. No database, custom inventory, alias, combo, pricing or capability records are rewritten. A saved direct-provider reference may still be shown or resolve but the vendor has shut down that direct model; users decide how to migrate it. No live provider was queried.
