The handler now accepts a complete JSON object followed solely by `data: [DONE]`, using the already-read text. It rejects other trailing data instead of silently hiding errors. The upstream patch attempts to read the body again after `.json()` fails; that cannot work on a consumed body. `nonstream-trailing-done-5384.test.js` covers nesting, escapes, rejection and the handler. |

| [#5378](https://github.com/decolua/9router/pull/5378) `3aa04e8195824942f71bad0b42f9f3df14eb96ec` | **Ported residual.** Existing namespace expansion and reverse identity maps preserve dotted names and collisions (`openai-responses-tool-name-map-4200.test.js`), metadata crosses translation hops, and Gemini strips the `encrypted` schema annotation while retaining a property of that name (`gemini-codex-encrypted-tool-schema.test.js`). OpenAI passthrough now holds framing until data arrives and drops field-only frames and dangling field tails, while preserving comment pings, tool/finish data and native Claude event framing. Buffering is bounded. `passthrough-sse-field-only-5441.test.js` exercises chunk boundaries and both formats; `port-3457-sse-keepalive.test.js` protects existing ping transport. |
