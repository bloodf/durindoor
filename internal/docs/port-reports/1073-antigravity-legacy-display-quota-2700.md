# #1073 OmniRoute #2700: Antigravity displayed quota fractions

Reviewed 2026-11-21 against exact OmniRoute pins: PR #2700 head `97bf881556685a6ce91348c44459716fc3152318`, merge `db9cc272e7d45b62b6becde59af5b8e469607da1`. The head changes the Antigravity usage service to clamp the `remainingFraction` used for percentage display to `[0, 1]`, defaulting absent/invalid values to exhausted; the separate fetcher also clamps its stored quota representation. The merge commit is an empty integration commit (0 files changed); its first parent is `1a88b75`. The local May comparison is `internal/docs/port-reports/1073-may-existing-executors.md`, whose bounded inventory does not cover this later May 26 PR.

Local scope is the existing legacy per-model row in `open-sse/services/usage/google.js` (`getAntigravityUsage`). The dashboard `ProviderLimits` path reads `remainingPercentage` via `getRemainingPercentage` and rounds it for the displayed row. The usage result also carries `used`, `total`, `resetAt`, and `unlimited`; those are not display-percentage aliases and must not be rewritten here. Grouped-model reconciliation also checks percentage for a zero-exhaustion signal; the original clamp inadvertently changed that signal for negative fractions. See [the reconciliation follow-up](1073-antigravity-display-reconciliation-2700.md). The grouped family parser already clamps its own finite fraction and classifies full no-reset buckets as unlimited.

Disposition: isolated existing behavior fix. Clamp only the finite legacy display fraction immediately before computing `remainingPercentage`. Preserve source-derived `used`/`total`, absent-value defaulting, reset parsing, unlimited metadata, grouped parser behavior, raw provider response, and all selectors, billing, preflight, authentication, persistence, and routing behavior. No fetcher/persisted quota path was changed. Offline mocked cases cover negative, above-range, valid in-range, absent, reset, legacy no-reset full quota, and grouped clamp/unlimited behavior. No live quota endpoint was called.
