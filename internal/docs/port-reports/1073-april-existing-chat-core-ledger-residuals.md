## Current runtime and evidence

DurinDoor's installed core is [`open-sse/handlers/chatCore.js`](../../../open-sse/handlers/chatCore.js); request normalization, execution, response selection, and terminal handling are implemented across its imported `chatCore/` helpers. Streaming selection is negotiated from the request and provider constraints by the current `streamFlag.js` path. Direct response selection and readiness are exercised by offline fixtures including `tests/unit/omni-json-under-sse-media-type.test.js`, `tests/unit/omni-stream-buffering-response-headers.test.js`, `tests/unit/omni-stream-safety-terminal.test.js`, and `tests/unit/omni-responses-incomplete-stream-usage.test.js`. These assert JSON-under-SSE handling, response headers, terminal/error mapping, and Responses usage completion. They do not establish parity with every OmniRoute internal timeout or monitoring feature. Request admission and terminal behavior remain governed by these installed paths.
