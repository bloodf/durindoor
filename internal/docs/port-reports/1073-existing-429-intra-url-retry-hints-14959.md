The prior qualification is `internal/docs/port-reports/1073-existing-intra-url-429-retry-window-14959.md`.

`open-sse/executors/base.js` declines an otherwise eligible generic same-URL 429 retry when a valid explicit wait exceeds the remaining configured delay window, bounded by remaining transport dispatches. A valid Retry-After takes precedence over locally recognized structured body evidence. The existing bounded clone reader fails open on unreadable or oversized evidence and propagates caller abort. Explicit retry rules and provider retry hooks retain ownership; existing fallback, response and dispatch handling remain in charge after a decline. This does not add retries, waiting, account handling, or headers.
