The scoped provider/model row now uses the verified standard rates; reasoning uses the output rate, and no cache-creation tariff is asserted. The calculator's existing missing-cache-creation fallback is input rate if such usage is supplied, not a vendor claim. Cached prompt tokens are subtracted from cache-inclusive input; reasoning is billed once whether reported as an output subset or as additive. Direct upstream USD costs take precedence in the calculator.

The database resolver merges editable user overrides over the resolved defaults and preserves override provenance. Usage accounting handles unpriced entries separately; a null price must not be described as free. The scoped row does not alter the generic pattern, other Gemini routes or Antigravity subscription quota, and does not establish their charging semantics. OmniRoute's subscription and cache-creation entries are not evidence for those charges here.
