## Scope boundary and acceptance

These comparisons concern format conversion and hygiene. `tool_search` and `image_generation` are Responses-native declarations which are preserved on the native Codex route and omitted only when lowering to Chat. The separate native image-generation request/response feature is not introduced by #2970. #2937 is a narrow Read argument sanitation rule; the existing OpenAI→Claude sanitizer is adjacent format hygiene, not proof of the missing Responses output case.

The sole demonstrated focused gap is #2937's Responses-output handling for JSON-string arguments. The ordinary offline acceptance above is sufficient for that gap; it needs no credentials, provider traffic, or end-to-end exercise. #2976's empty-ID case is already subsumed by the local missing-ID repair contract and its tests.

Do not conflate these four PRs with pending [9router #5496](https://github.com/decolua/9router/pull/5496) terminal work. The repository's existing [#5496 assessment](1072-9r-codex-claude-search-5496.md) records terminal-output accumulation concerns separately; none of these OmniRoute PRs changes or resolves that terminal behavior.
