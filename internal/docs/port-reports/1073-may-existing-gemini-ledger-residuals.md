# #1073 May Gemini protocol inventory: existing ledger residuals

This audit compares the pinned OmniRoute public changes with the installed DurinDoor source and offline fixtures. A matching filename is not treated as protocol parity. Gemini Developer API (`gemini`), Gemini CLI Cloud Code Assist (`gemini-cli`), Antigravity Cloud Code (`antigravity`/`agy`), and Gemini web are separate surfaces. No source-only new modes, browser integration, login, or provider additions are proposed.
