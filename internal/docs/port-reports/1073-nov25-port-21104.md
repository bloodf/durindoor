# OmniRoute #21104 proxy session rotation port

DurinDoor rotates among active proxy pool records for public no-auth providers. It does not have OmniRoute's scoped proxy registry and its account, provider, combo, and global member pools. This port applies session affinity to DurinDoor's existing rotation path. A session uses rendezvous scoring over active pool IDs; without a routing session ID it falls back to round-robin. A removed or inactive pool only remaps sessions assigned to that pool, and restoring it restores their assignments. The default remains the existing single-pool selection.
