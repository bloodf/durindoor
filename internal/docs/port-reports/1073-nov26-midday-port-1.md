## Notes for the owner

- **#3936 changes what the model sees.** Trailing assistant text or tool calls now reach the model, followed by a continuation or an error tool result. Before, they were dropped. Other Claude targets already behaved this way. The titles in the unchanged strip test still say "strips". The source row marked this "Owner decision"; revert its commit if dropping the turn was intended.
- **#3863 changes the default on small hosts.** When `os.totalmem()` reports less than 8192 MB, the launcher now sets a lower cap than 6144 MB. The "existing 6144 MB default" title in the unchanged heap test now covers the helper without a memory figure. `NINEROUTER_MAX_OLD_SPACE_SIZE` and `NODE_OPTIONS` still override the default.

## Limits

- **#20457.** The default shortens existing locks: a countdown above 6 hours was honored up to 7 days. After the ceiling expires the account is tried again, and an unreset window locks it again. Upstream's combo exhaustion changes were not needed, because combo members lock through the same writer.
- **#20433.** Upstream hides the prefix from every engine. Only the lite truncation was guarded here, because the source row names it as the gap. The other engines were not audited for turn-dependent output. For listed caching providers, truncation now does nothing without a marker unless the request exceeds the context window. The provider list is adapted from upstream and was not checked against live cache billing.
- **#20416.** Executors that override `execute` without calling the base were not changed.
- **#3871.** `HEAD` is unchanged. Bare ids of custom or live-discovered models that are not in the registry still return `Unknown model kind`.
- **#3863.** The cap follows `os.totalmem()`, as upstream does. A container memory limit was not read or tested, so set the heap explicitly there if needed. The server was not started under a memory-limited host.
- No live provider was called. The full suite was not run.
