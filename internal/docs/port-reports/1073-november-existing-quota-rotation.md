## Current DurinDoor evidence

- [`src/sse/handlers/chat.js`](../../../src/sse/handlers/chat.js) selects credentials through `getProviderCredentialsWithQuotaPreflight` at the start of each request attempt. When a retryable provider failure adds the current connection to `excludeConnectionIds`, the outer loop returns to this selector for the next account. The same request model candidates, quota family, resource keys, allowed-connection scope, and API-key scope are supplied on each selection.
- [`src/sse/services/auth.js`](../../../src/sse/services/auth.js) implements the existing preflight wrapper. It checks selected account snapshots, refreshes stale quota evidence through injected loaders/refresher, excludes denied accounts for reselection, and returns the established `allRateLimited` result if no eligible account remains. Its documented failure behavior preserves original credential selection when refresh fails, while propagating aborts.
- [`tests/unit/provider-quota-preflight-selection.test.js`](../../../tests/unit/provider-quota-preflight-selection.test.js) exercises offline deterministic cases: exhausted first account selects the next eligible account; a sole exhausted account returns `allRateLimited` with persisted retry metadata; refresh errors fail open; refresh is bounded once per connection; and abort propagates. [`tests/unit/provider-quota-preflight.test.js`](../../../tests/unit/provider-quota-preflight.test.js) and [`tests/unit/provider-quota-policy.test.js`](../../../tests/unit/provider-quota-policy.test.js) cover evaluation policy and reservation-aware decisions.

## Disposition

No product change is indicated for these pins. #19726 is an OmniRoute source-inventory and selector-visibility repair; DurinDoor's normal account-retry path already re-enters quota-preflight selection for each excluded-account retry. #20561's actual policy change is specific to Quota Share, which is absent here, so importing that behavior would introduce an unrelated policy. No focused evidence gap was identified for the requested existing Codex/general quota-preflight behavior; the cited offline tests are the ordinary acceptance evidence. No real account, quota, credential, or provider traffic was used.
