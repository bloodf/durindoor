# Responses tool and usage comparison (#1073)

Compared OmniRoute #19599 head `27a7cd597e73da9c7d94c1d7f7b4f512e9b17d53` and merge `1d265aa0ba2b14d263912f0b722aeaed56f554d3` with this integration tree, using the upstream PR patch and the existing Responses stream translator.

- **Escaped tabs:** The upstream fix restricts an existing double-escaped-tab repair to Luna. This tree has no such repair in the Responses tool stream: `emitToolCall` appends and emits function argument fragments verbatim, and `closeToolCall` parses the wrapper only for custom tool input. Therefore the broad corruption fixed upstream is absent, including for Luna function calls. Synthetic round trips check every split of a literal backslash-t. No repair is introduced for patch input: a literal backslash-t is ambiguous without independent evidence that a particular patch input was over-escaped. Custom input continues to use the existing JSON wrapper decoding.
- **Usage:** `completedUsage` already rejects zero placeholders, uses `toResponsesUsage`, and stores the projection separately from shared accounting. The residual gap was projecting only the current chunk even though shared usage is accumulated. Project accumulated shared usage when a usage chunk arrives, preserving existing normalization and accounting fields. A synthetic stream checks counters split across chunks and preserved cost and credits. Responses-to-Chat continues to normalize the terminal event through `toResponsesUsage` and `buildUsage`.
- **Done-only tools:** Added-then-done already emits a header on `response.output_item.added` and recovers full arguments on `response.output_item.done` when no deltas were emitted. A call first seen in done previously emitted arguments without a header or a distinct index. Route it through the existing added handling before processing done; synthetic parallel calls check identity, exact arguments and one terminal finish. An anonymous done following an added call remains associated with the current call, as covered by the existing golden stream and a focused regression test. Chat-to-Responses already emits added, argument deltas and done from accumulated fragments. No output-index allocation policy was changed.

Validation is offline and uses synthetic stream frames. It does not establish provider-specific over-escaping or live billing behavior.
