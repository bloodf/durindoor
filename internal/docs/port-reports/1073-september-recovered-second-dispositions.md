## Deep comparisons — five current existing provider/protocol fixes

These five are current fixes to existing providers or protocol surfaces in this fork. For each, the exact final upstream diff was fetched read-only (`gh pr diff`, `cheaper-inference/OmniRoute`) and compared with the local implementation and its local fixtures.

1. **#14692 — Command Code Responses routing.** Upstream routes a Responses-shaped body to `/provider/v1/responses` because the flat chat surface drops `reasoning.effort`. The fork posts every Command Code request to `https://api.commandcode.ai/alpha/generate` (`open-sse/providers/registry/commandcode.js:26`, `open-sse/executors/commandcode.js:42`) and has no flat chat surface, so there is nothing to re-route. Adding it would be feature scope, not a fix port.
2. **#14738 — Grok CLI tool shapes.** Upstream hoists Responses `additional_tools` envelopes into `tools` and converts freeform `custom` tools for Grok Build, with a reverse restore. The fork's `normalizeGrokCliTools` (`open-sse/executors/grok-cli.js:199-259`) rewrites a `{type:"custom"}` tool into a bare `{type:"function"}` with an empty schema, never restores `custom_tool_call`, and never hoists `additional_tools` for this lane (the only local handling is Codex-specific, `open-sse/handlers/chatCore.js:727-734`). **Actionable residual.**
3. **#14735 — Cursor HTTP/2 proxy.** Upstream tunnels the Cursor h2 agent stream through the configured proxy (`open-sse/executors/cursor/h2ProxyConnect.ts`, `h2AgentStream.ts`). The fork opens h2 directly (`open-sse/executors/cursor.js:609`) and fails the request closed whenever a proxy applies (`open-sse/executors/cursor.js:827-831`). **Actionable residual:** the Cursor AgentService lane is unusable behind any proxy and has no local tunnel module.
4. **#14814 — Claude tool input normalization.** Upstream guarantees an object `input` on every Claude `tool_use` block. The fork still uses the raw-string fallback (`open-sse/translator/request/openai-to-claude.js:430`), so a non-object `arguments` value reaches Anthropic as a non-object `input`. **Actionable residual**, with upstream `tests/unit/translator-openai-to-claude-tool-input-14798.test.ts` as the reference case set.
5. **#15090 — Codex Responses subpath traversal.** Upstream forwards a client-supplied `/v1/responses/<subpath>` and refuses an unsafe one (`open-sse/executors/codex/responsesSubpath.ts`). The fork builds the Codex URL from the configured base plus a boolean `/compact` suffix only (`open-sse/executors/codex.js:676-679`), exposes only `/v1/responses` and `/v1/responses/compact`, and answers every other `/v1/*` path with `not_found`. No client-controlled subpath is forwarded, so there is no traversal seam to close.
