## Parts of #5032 not ported

- Upstream replaces all system and developer messages with one `You are CodeBuddy Code.` system message. DurinDoor keeps the client's roles, order and unmatched bytes (#3823 and 9router #5796).
- Upstream also rewrites assistant history. [codebuddy-system-prompt-len-3339.test.js](../../../tests/unit/codebuddy-system-prompt-len-3339.test.js) pins that DurinDoor never rewrites non-system messages, so it still does not. A marker quoted in an assistant turn still reaches CodeBuddy.
- Upstream adds `X-Stainless-*`, `X-App`, `X-Domain` and `X-Agent-*` headers with fixed client values, including a fixed operating system. Nothing in this repository shows the gateway requires them.
- CodeBuddy CN token refresh already exists in [default.js](../../../open-sse/executors/default.js). CodeBuddy International is API key only here, so its OAuth changes do not apply.

Whether the ported markers clear error 11128 is unverified: no request was sent to CodeBuddy.
