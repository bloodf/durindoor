## Behaviour change to note

A caller with only a dashboard session cookie must now send `currentPassword` to weaken these settings or change sign-in settings. This includes an OIDC-only operator, who needs the local dashboard password. One expectation in [settings-mass-assignment.test.js](../../../tests/unit/settings-mass-assignment.test.js) changed for this reason. See [Security](../../../docs/operations/security.mdx#changing-security-settings).
