# Port report — open PR batch 17, port candidates 1–8

Scope: port candidates 1–8 of [the batch 17 dispositions](open-prs-nov25-17.md), counted over port-candidate rows in table order. All are `decolua/9router` PRs. On 2026-11-25 each PR was open and its current diff was fetched with `gh api`. Each head matched the SHA in its source row.

Most of these PRs already had an earlier port on this branch, so each upstream diff was compared with the current code. Three had a part that was still missing. A temporary probe test checked the Codex effort, `additional_tools` and Responses `text` behaviour before any change.
