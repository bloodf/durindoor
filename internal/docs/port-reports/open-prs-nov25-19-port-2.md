## Behaviour of the ports

- #21140: when only the client's abort signal fires, the stream still errors with `AbortError`.
- #21119: a `StreamGenerate` answer or error status ends the wait first. An unreadable `StreamGenerate` body leaves the page read running. Differing from upstream, an error status such as `429` does not wait for the page, and Enter is not repeated when the page cannot be read.

## Parts of #21119 not taken

- Gemini 4 menu modes, their longer timeout and the check for a model swapped under high demand: new models and a new menu-selection path. The local catalog and mode selection are unchanged.
- Keeping an upstream error code after every connection is exhausted: this changes gateway error responses for all providers and is outside the row's gap. After exhaustion, the client may not receive the `gemini_web_signed_out` code.
