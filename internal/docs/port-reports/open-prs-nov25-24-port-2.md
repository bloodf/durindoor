## Parts of #20105 not ported

- **API key delivery (open question).** Upstream says Codex ignores `auth.json` for a custom provider, so it moves the key to `env_key` and `~/.codex/.env`. DurinDoor still writes `OPENAI_API_KEY` to `auth.json` and sets no `env_key`. The Codex client was not run here, so the claim is unverified. The change would also add a secret file and require every user to apply again. Check it against a real Codex client before changing it.
- **Restore swap gate: not ported.** DurinDoor's database import runs in a transaction. Its cutover rollback in `src/lib/db/cutover.js` does copy a snapshot over the live file. The active adapter stays installed during that copy, and the cutover lock is meant to reject writes. This was read in the source, not tested.
- **Not applicable:** the CLI backup route is absent. Hermes profile selection, the reload hint and extra catalog metadata are new features.
