## Open items found while porting

These were not changed.

- **The cache-key opt-in is discarded on custom nodes.** The executor injects the key, then [the wire guard](../../../open-sse/translator/concerns/paramSupport.js) deletes `prompt_cache_key` unless the transport declares `preservePromptCacheKey`. Custom OpenAI-compatible nodes do not. The key reaches the upstream only on transports with that quirk, such as `openai`.
- **The colocated cache-key test does not run as written.** `node --test` could not resolve the `open-sse` package alias, with or without the repository alias loader. A temporary Vitest copy passed 11 of 12 cases. The failing case expects the key to survive on a custom node, which is the guard above.
- **Codex cache key.** [The Codex executor](../../../open-sse/executors/codex.js) can still use the session id itself as `prompt_cache_key`. It was not changed.
- **Bedrock effort.** Bedrock Converse forwards `thinking` but not `output_config.effort`, so a requested effort does not reach Bedrock.
- **Fable 5.2 quota window.** [Quota preflight aliases](../../../open-sse/config/providerQuota.js) map Fable 5.1 and 5 to the Fable window, not 5.2. Which window 5.2 uses was not verified.
