## Limits and open items

These were not changed.

- **Age restriction response shape.** No live response was available. The default-tier exception comes from the response fields, not from a captured age-restricted account.
- **Private endpoint detection.** The cap reads the saved URL's host. It does not resolve a public-looking name that points to a private address. A connection with no saved base URL is unchanged.
- **Synchronous video.** [The synchronous video handler](../../../open-sse/handlers/videoGenerationCore.js) and its executor were not given the cap. The source row names only the job proxy.
- **Kiro catalog.** DurinDoor still does not follow `nextToken` pages. The catalog does not look up a missing ARN for IAM Identity Center or other imported logins. Upstream's PR changes both, and its version-gate handling was not compared by test.
