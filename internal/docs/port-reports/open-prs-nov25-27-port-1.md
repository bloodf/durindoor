## Limits and open items

- **#18313 parts not ported.** The XML dialect recovery ladder beyond `<tool>` and `<tool_call>`, lenient JSON repair, fuzzy tool-name resolution (only case and separator differences match), flattened arguments, the repair retry and its strict-recovery flag, the contract reminder, reasoning-channel reading and the added `deepseek-v4.1-flash-1017` catalog model. Replies in those shapes stay text and run nothing.
- **Repair retry.** At the fetched head the PR asks the model again after an unusable reply. Here that would send a second quota-bearing request inside one execution, so it needs its own attempt accounting.
- **Unverified upstream facts.** The Adapta catalog keys and body shape, and the playground's limits of 6000 characters and 10 user messages, come from the two pull requests. Tests use closed mocks and no live provider was called.
- **Provider catalog page.** `docs/providers/catalog.mdx` was already stale for other providers at the starting commit. Only the Adapta model count was updated.
