After DurinDoor is running, these pages cover the client side: mint a gateway key, pick a model string, send traffic through an SDK, watch what happened, and script the dashboard REST or MCP control server. Combos, provider login, and the dashboard map live in other sections. Start with a key if you have none; the SDK page assumes you already have a secret and a model id.
