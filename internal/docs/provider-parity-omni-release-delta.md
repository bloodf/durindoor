Custom OpenAI-compatible Chat Completions connections can opt in to **Strict chat history** in the connection editor. It merges consecutive user or assistant text turns, with a newline and replaces empty user or assistant text with a space. The setting defaults off and does not apply to Responses, Anthropic, or other providers. Histories containing tools, multimodal content, or additional message fields pass through unchanged to preserve their data and ordering. This connection-level repair is based on OmniRoute #20286 / #19762 (`open-sse/utils/strictChatHistory.ts`).
