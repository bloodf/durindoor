# Qualification of open OmniRoute provider tickets

## Pinned source and method

Reviewed 2026-11-20 against DurinDoor `origin/main` **`bc2b597a4bd9f3e09dba0f4ed12b3e778b43de17`** and OmniRoute `release/v3.8.55` **`575c3d49c15b2ff444e39c83a6ee648f19a2923e`**. This review starts from the merged [OmniRoute provider contract inventory](provider-parity-omniroute.md), which records an earlier OmniRoute snapshot. The live release ref was pinned independently for this qualification. Issue numbers below always identify `bloodf/durindoor` issues; provider evidence is matched by provider ID and pinned source path, never by assuming the same issue number upstream.

Checked the seven named issues, their `source:omniroute` label, their described source contract, the current pinned upstream registry composition and provider modules, auth/default executor behavior, catalog/discovery settings and executor dispatch. Compared those with DurinDoor main's generated provider registry and available route/executor wiring. Source and mock fixtures are the evidence; no live provider requests or account credentials were used. A registry entry or offline fixture does not establish live service availability.

## Summary and limits

Five issues identify contracts absent from pinned DurinDoor main: `devin-cli-agentic`, `freebuff`, `nlpcloud`, OAuth `openference`, and `xkiro`. Two report contracts already registered equivalently: `speka` and `zerolimitai`. No upstream removal was found for these seven identities in `release/v3.8.55`; each appears in its composed registry. The upstream inventory's pinned commit predates this release snapshot, so its bulk inventory remains useful context but is not the source of truth for these row-level conclusions.

The classifications qualify source parity only. The report does not accept or close issues, verify provider accounts, establish current pricing or live availability, or authorize implementation. Actionable gaps need local mocked tests and documentation if implementation is later approved. The only changes for this work order are this source review and documentation.
