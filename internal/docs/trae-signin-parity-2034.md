# Trae sign-in and request comparison (#2034)

CLIProxyAPI at `6faa8d20b2673404cff70a2f2d9537ae0d0e684d` has no Trae registration in its [executor dispatch](https://github.com/router-for-me/CLIProxyAPI/blob/6faa8d20b2673404cff70a2f2d9537ae0d0e684d/sdk/cliproxy/service_executors.go). EasyCLIProxyAPI at `e4223d5eefa22a3301ca7e2a28d05897432b07f9` delegates login and status to its managed core through its [management API bridge](https://github.com/router-for-me/EasyCLIProxyAPI/blob/e4223d5eefa22a3301ca7e2a28d05897432b07f9/src-tauri/src/management_api.rs). Neither pinned tree contains a Trae-named path. That inventory covers built-in support.

OmniRoute at `e3c1531afd07d5e06f7ffab658584a7ae2e3627e` has two session paths. The [paste import route](https://github.com/cheaper-inference/OmniRoute/blob/e3c1531afd07d5e06f7ffab658584a7ae2e3627e/src/app/api/oauth/trae/import/route.ts) stores an access token with a 14-day expiry and no refresh token. The [provider mapper](https://github.com/cheaper-inference/OmniRoute/blob/e3c1531afd07d5e06f7ffab658584a7ae2e3627e/src/lib/oauth/providers/trae.ts) also supports refresh credentials from the separate authorize callback path. DurinDoor retains the approved import through `POST /api/oauth/trae/import-token`. Imported sessions use the configured default lifetime and require a new import after expiry.

The [OmniRoute executor](https://github.com/cheaper-inference/OmniRoute/blob/e3c1531afd07d5e06f7ffab658584a7ae2e3627e/open-sse/executors/trae.ts) creates a SOLO chat session and consumes the event stream for its reply ID. DurinDoor already used its fixed Trae API host, the `Cloud-IDE-JWT` authorization scheme, code and work modes, and OpenAI-formatted output. [OmniRoute #13255](https://github.com/cheaper-inference/OmniRoute/pull/13255) established the updated Origin and Referer default and optional timezone header. DurinDoor applies those changes and persists region, language, version, identity and timezone from the import for the selected connection. The web origin affects request headers only.

The static [OmniRoute registry](https://github.com/cheaper-inference/OmniRoute/blob/e3c1531afd07d5e06f7ffab658584a7ae2e3627e/open-sse/config/providers/registry/trae/index.ts) supplies the nine SOLO model IDs, alias `tr`, and default context length of 272000. DurinDoor publishes them through its registry without adding a dynamic model-list endpoint.

The closed mock suite covers token validation and omission from import responses, connection-specific credentials, session creation and event handling, and catalog resolution. Live token validity, header acceptance, and current account-specific model availability remain unverified. The upstream authorize callback, refresh exchange, and applied-proxy status capture remain outside this port.
