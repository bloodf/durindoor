Ported work is recorded by `scripts/upstream-ported-ids.sh`:

1. Commit subjects `port(upstream): #N - ...` or `port(upstream): #A+#B - ...`. Every number in the leading `#A+#B` group counts; a trailing `(#123)` is this repository's squash number.
2. `.github/upstream-ported.json` `ported[].pr`, for PRs with no `port(upstream)` subject of their own. Membership is source-qualified: only `source: "decolua/9router"` or legacy rows without a `source` field count in the 9router scan. `CHANGELOG.md` is not parsed for membership.

## Scan workflow

`.github/workflows/upstream-watch.yml` is `workflow_dispatch` only. A comment in the file calls it an emergency fallback with no scheduled runs.

On dispatch it:

1. Lists open PRs from `decolua/9router` (`gh pr list --state open --limit 1000`).
2. Builds the ported set with `scripts/upstream-ported-ids.sh`.
3. Writes `report/body.md` and `report/comment-NNN.md` via `scripts/upstream-scan-report.sh`.
4. Creates or updates a tracking issue labeled `upstream-scan`.

The workflow needs `issues: write` and `contents: read`. It uses `GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`.
