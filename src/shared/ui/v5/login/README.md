The Storybook login preserves the production LoginView prop contract and renders the website's actual split-doorway BrandMark. The production page continues to own password, MFA, OIDC, password-change and redirect behavior.

The scene ray-marches a physical 3D arch and rotating door leaf in WebGL. It limits device pixel ratio, pauses while hidden, renders one frame for reduced motion, exposes a pause control, cleans GPU resources on unmount and uses a CSS perspective doorway if WebGL cannot start. The form stays in a separate region; the scene does not receive pointer events except its pause control.

In production, `DURINDOOR_UI_V5` selects the doorway layout around the existing
login forms. Password, MFA, OIDC and password-change handlers remain owned by
the production page. The callback status view announces its result and offers
a sign-in link after an error when V5 is enabled.
